# 021 · Agent Skills como base do desenvolvimento

**Data:** 2026-11-27
**Status:** proposta

## Contexto

A pessoa pediu que o repositório se concentrasse no desenvolvimento baseado no Agent Skills, com o fluxo existente e trabalho em tarefas pequenas. O fluxo 9.0.0 mantinha um índice de lições, artefatos do Superpowers e uma integração de segurança separada.

## Decisão

Usar as práticas do Agent Skills para descoberta, desenho, plano, construção, revisão, Git, publicação e manutenção. O AI Development define quando uma prática se aplica, quem decide e onde registrar a evidência. O desenvolvimento usa incrementos verificáveis. O Security usa `security-and-hardening`, com parecer independente conforme a ferramenta.

Retirar as áreas de lições, casos e Superpowers do repositório ativo. A retrospectiva do projeto fica na memória do projeto. Mudanças de regra do método continuam registradas nas decisões. [Auditoria e tarefas](../planos/2026-11-27-adocao-agent-skills.md)

## Consequências

- A Lead pode conduzir um ajuste básico com aceite curto, verificação focada e CI. Trabalho mais amplo recebe testes, revisão e aprovações proporcionais.
- A preparação usa o gerador existente. Projetos já configurados aplicam as mudanças com um diff dos modelos.
- A revisão abrangente de segurança conserva escopo, autorização, tratamento privado da evidência e bloqueio de riscos confirmados críticos ou altos.
